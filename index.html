Meu Projeto

Uma página simples criada com HTML e CSS

Sobre o projeto

Este projeto apresenta uma página inicial desenvolvida para praticar conceitos básicos de programação web.

O que utilizei

HTML para organizar o conteúdo e CSS para definir cores, espaçamentos e aparência da página.

O que aprendi

Aprendi como estruturar uma página, criar seções e aplicar estilos para deixar o conteúdo mais organizado e agradável.

Projeto desenvolvido como atividade de aprendizagem.
